# v20.0.0 Reliable Daily Quotas

AI Usage Monitor now separates authenticated quota observations from local tool
activity. Old or reset quota windows stop driving the live panel until fresh data
arrives. The lowest quota and earliest reset are selected independently, and
countdowns share one clock across the daily interface.

The tooltip consumes normalized daily rows for both API providers and local
tools. Source Detail labels retained observations as last known. Available zero
remains a real exhausted quota; missing values are unavailable. Source cards
prioritize authenticated quota over locally configured activity targets.

Subscription prices and allowances have individual evidence dates and expiry.
Published price ranges stay ranges; unknown totals are not synthesized. Current
account telemetry is independent of expired static catalog evidence. Unresolved
Windsurf transitions and historical Copilot request contracts remain under review.

After wake or network recovery, automatic refreshes coalesce and respect retry
policy. Authentication and configuration errors require corrective action;
Retry-After prevents premature API and browser-sync retries.

## Installation

Fedora COPR and source installs include the native plugin and Plasma frontend.
The KDE Store archive is frontend-only and requires the matching 20.0.0 native
plugin. Restart Plasma after updating both layers.
